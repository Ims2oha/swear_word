# Qwen 생성 프롬프트: 유형 E / F / G

`./delegate-worker`로 Qwen에 보내서 순화 쌍을 만든다. 평가에서 나온 실패를 겨냥한 세 유형이다.

| 유형 | 겨냥하는 실패 | 정답 |
|---|---|---|
| E | 욕이 여러 개면 첫 번째만 고침 | 욕 2~3개를 모두 순화, 나머지는 그대로 |
| F | 비하 명사를 잘라 먹거나 뜻을 바꿈 (`찐따→찐`, `맘충들이랑→엄마들이랑`에서 문장 잘림) | 비하 명사만 중립 표현으로, 문장은 끝까지 |
| G | 욕처럼 보이는 깨끗한 문장을 고침 (`쓰레기 양`, `죽어버린`) | 입력 그대로 (input == target) |

## 파일 규칙 (`src/build_llm_pairs.py`가 읽는 형식)

- 저장 위치: `data/llm_pairs/raw/{주제}_{유형}.txt` (예: `게임_E.txt`, `직장_G.txt`)
- 한 줄에 JSON 하나: `{"input": "...", "target": "..."}`. 다른 글은 쓰지 않는다.
- 기존 유형 글자와 겹치면 E/F/G 대신 안 쓰는 글자로 바꾼다. G를 바꾸면 `build_llm_pairs.py`의 `IDENTITY_TYPES`도 같이 바꾼다.
- 주제 예: 게임, 직장, 학교, 연애, 스포츠, 뉴스·정치, 음식, 쇼핑, 커뮤니티, 친구 잡담, 가족, 연예인
- 양: 주제마다 유형별 150~300줄. 한 번에 30줄씩 요청하고 여러 번 돌린다.

생성 후:
```bash
.venv/Scripts/python src/build_llm_pairs.py      # 걸러서 data/llm_pairs/llm_pairs.jsonl 생성, build_report.json 확인
.venv/Scripts/python src/prepare_data.py
.venv/Scripts/python src/train.py && .venv/Scripts/python src/evaluate.py && .venv/Scripts/python src/eval_moderate.py
```
`build_report.json`의 drops에서 많이 버려진 사유를 보고 프롬프트를 고친다. `review_pool.jsonl`에서 조합(`combo`)별로 몇 줄씩 직접 읽어 본다.

## 걸러지는 조건 (프롬프트에 이미 반영함)

- 입력 8~80자, 정답 길이는 입력의 0.5~1.5배
- 정답에 욕(lexicon 단어)이 남으면 버림
- 정답에 입력에 없던 숫자·영어 단어가 생기면 버림
- 한자·가나, "죄송/AI/순화/프롬프트" 같은 말이 있으면 버림
- 같은 정답이 6번 넘게 나오면 버림
- "그만해", "하지마", "말조심해" 같은 짧은 고정 문장이 정답이면 버림

## 유형 E: 욕 여러 개

```
너는 한국어 온라인 채팅 데이터를 만드는 사람이다.
주제 "{주제}"에 대해 사람들이 실제로 디스코드·커뮤니티에서 쓸 법한 반말 구어체 문장을 만들고, 그 문장의 순화문을 짝으로 써라.

입력(input) 조건
- 한 문장 안에 욕설·비속어가 2개 또는 3개 들어간다. 서로 다른 종류를 섞는다:
  강조 욕(존나, 졸라, 개-, 씨발 같은 부사), 감탄 욕(아 씨발, 와 미친, 지랄), 사람을 욕하는 말(병신, 새끼, 또라이, 찐따, 븅신),
  비하 표현(~충, 틀딱 등), 문장형 욕(닥쳐, 꺼져, 좆같네)
- 욕이 문장 앞, 중간, 끝에 고루 나오게 한다. 첫 단어에만 몰리지 않게 한다.
- 8자 이상 80자 이하. ㅋㅋ, ㅠㅠ, 줄임말 같은 채팅 말투를 자연스럽게 섞는다.

정답(target) 조건
- 입력에 있는 욕을 하나도 빠짐없이 모두 순화한다.
  강조 욕 -> "너무/진짜/정말"로 바꾸거나 뺀다
  감탄 욕 -> 뺀다
  사람을 욕하는 말·비하 표현 -> 문맥에 맞는 중립적인 말로 바꾼다 ("그 사람", "걔", "이상한", "학생들" 등).
    "바보", "멍청이" 같은 다른 욕으로 바꾸지 않는다
  문장형 욕 -> 같은 뜻의 공손한 말로 바꾼다 (닥쳐 -> 조용히 해줘)
- 욕이 아닌 부분은 단어, 어미, 말투, ㅋㅋ/ㅠㅠ까지 그대로 둔다. 문장을 자르거나 내용을 빼지 않는다.
- 뜻을 바꾸지 않는다. 입력에 없는 내용, 숫자, 영어 단어를 새로 넣지 않는다.
- 길이는 입력과 비슷하게 (절반보다 짧거나 1.5배보다 길지 않게).

출력 형식
- 한 줄에 JSON 하나: {"input": "...", "target": "..."}
- {N}줄을 출력하고 다른 말은 쓰지 않는다. 같은 문장을 반복하지 않는다.

예시
{"input": "아 씨발 오늘 팀플 존나 길었는데 조장 새끼가 또 늦음", "target": "아 오늘 팀플 너무 길었는데 조장이 또 늦음"}
{"input": "이 병신 같은 패치 누가 했냐 존나 짜증나네 ㅋㅋ 개발자들 다 꺼져", "target": "이 이상한 패치 누가 했냐 진짜 짜증나네 ㅋㅋ 개발자들 좀 반성해"}
{"input": "와 미친 저 또라이 또 신호 무시하고 감 개념 없네 진짜", "target": "와 저 사람 또 신호 무시하고 감 생각이 없네 진짜"}
```

## 유형 F: 비하 명사 (문장은 끝까지 지키기)

```
너는 한국어 온라인 채팅 데이터를 만드는 사람이다.
주제 "{주제}"에 대해, 사람이나 집단을 비하하는 명사가 들어간 반말 구어체 문장과 그 순화문을 짝으로 써라.

입력(input) 조건
- 비하 명사가 1~2개 들어간다. 예: 찐따, 맘충, 급식충, 틀딱, 한남충, 김치녀, 된장녀, 짱깨, 쪽바리, 기생충(사람을 가리킬 때),
  설명충, 진지충, 관종, 흑우, 노인네, 꼰대, 씹선비, 오타쿠 비하, 지역 비하, 직업 비하 등. 주제에 맞는 것을 고른다.
- 비하 명사 뒤에 조사(들, 이, 가, 은, 는, 을, 를, 이랑, 처럼, 한테)가 붙는 문장을 많이 만든다.
- 비하 명사가 문장 앞이 아니라 중간이나 끝에 오는 문장도 많이 만든다.
- 8자 이상 80자 이하.

정답(target) 조건
- 비하 명사만 중립적인 표현으로 바꾼다. 예: 찐따 -> 소심한 사람, 맘충 -> 엄마들, 급식충 -> 학생들, 틀딱 -> 어르신들,
  짱깨 -> 중국 사람, 꼰대 -> 윗사람, 설명충 -> 설명 많은 사람
- 바꾼 말에 맞게 조사를 고친다 (찐따가 -> 소심한 사람이).
- 나머지 문장은 끝까지 그대로 둔다. 뒷부분을 자르거나, 절을 빼거나, 뜻을 바꾸지 않는다.
- 단어를 반만 남기지 않는다 (찐따 -> 찐 같은 결과 금지).
- 입력에 없는 내용, 숫자, 영어 단어를 새로 넣지 않는다.

출력 형식
- 한 줄에 JSON 하나: {"input": "...", "target": "..."}
- {N}줄을 출력하고 다른 말은 쓰지 않는다. 같은 문장을 반복하지 않는다.

예시
{"input": "주말에 마트 갔는데 맘충들이 카트 길막하고 수다 떨어서 한참 기다림", "target": "주말에 마트 갔는데 엄마들이 카트 길막하고 수다 떨어서 한참 기다림"}
{"input": "고독을 즐기는 찐따랑 인정받는 찐따는 다르다니까 ㅋㅋ", "target": "고독을 즐기는 소심한 사람이랑 인정받는 소심한 사람은 다르다니까 ㅋㅋ"}
{"input": "회의 때마다 꼰대가 라떼 얘기만 해서 시간 다 감", "target": "회의 때마다 윗사람이 옛날 얘기만 해서 시간 다 감"}
```

## 유형 G: 욕처럼 보이지만 깨끗한 문장 (그대로)

```
너는 한국어 온라인 채팅 데이터를 만드는 사람이다.
주제 "{주제}"에 대해, 욕처럼 보이는 글자가 들어 있지만 실제로는 전혀 욕이 아닌 평범한 반말 구어체 문장을 만들어라.
정답(target)은 입력(input)과 글자 하나 다르지 않게 똑같이 쓴다.

들어갈 말의 예 (일반적인 뜻으로만 쓴다)
- 쓰레기(물건): 쓰레기 버리기, 쓰레기 양, 쓰레기통, 분리수거
- 죽다(사람 아닌 것, 또는 담담한 서술): 배터리 죽었어, 화분이 죽어가, 웃겨 죽겠다, 렉 때문에 캐릭터가 죽었어
- 시발점, 개최, 개발, 개구리, 개나리, 강아지 새끼, 새끼손가락, 미치다(영향을 미치다), 불이 꺼져, 홍어(음식), 게이지, 십팔번(애창곡), 조지아(나라)
- 비슷한 소리: 수박씨 발라 먹기, 신발 끈, 시베리아, 졸라맨(캐릭터), 졸라서(조르다)

입력 조건
- 위 같은 말이 1~2개 자연스럽게 들어간다. 욕, 비하, 비꼬기는 절대 넣지 않는다.
- 다음 말은 쓰지 않는다: 씨발, 병신, 존나, 좆, 지랄, 개새끼, 개꿀, 빡치다, 똥겜, 깽판, 노답
- 8자 이상 80자 이하. 채팅 말투(ㅋㅋ, ㅠㅠ, 줄임말)를 섞는다.

출력 형식
- 한 줄에 JSON 하나: {"input": "...", "target": "..."}  (target은 input과 똑같이)
- {N}줄을 출력하고 다른 말은 쓰지 않는다. 같은 문장을 반복하지 않는다.

예시
{"input": "시험기간이라 쓰레기 양이 장난 아니게 늘었대 ㅋㅋ", "target": "시험기간이라 쓰레기 양이 장난 아니게 늘었대 ㅋㅋ"}
{"input": "폰 배터리 죽어서 연락 못 했어 ㅠㅠ 미안", "target": "폰 배터리 죽어서 연락 못 했어 ㅠㅠ 미안"}
{"input": "이번 사건의 시발점이 결국 그 공지였네", "target": "이번 사건의 시발점이 결국 그 공지였네"}
```
